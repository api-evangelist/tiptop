# Tiptop

> Tiptop (Tiptop Labs, founded by Postmates co-founder Bastian Lehmann, backed by a16z) is a payments company whose product lets shoppers trade in items they own for instant credit at checkout, alongside pay-over-time options. Merchants integrate via a Shopify payments app, Salesforce Commerce Cloud cartridge, Magento 2 module, or a Direct API built on the tiptop.js browser library plus three server-side order-management endpoints authenticated with an api-key header. Note: as of July 2026 tiptop.com redirects to mother.ai (Mother Computer Inc.); the developer docs, API hosts, and packages remain live.

## APIs

Production API host: https://api.tiptop.com/ (staging: https://api-stage.tiptop.com/). JSON requests with an `api-key` header.

- [Capture API](https://docs.tiptop.com/direct/order-management-apis/capture/): POST /v1/direct/order/capture-request
- [Void API](https://docs.tiptop.com/direct/order-management-apis/void/): POST /v1/direct/order/void-request (optional partial amount)
- [Refund API](https://docs.tiptop.com/direct/order-management-apis/refund/): POST /v1/direct/order/refund-request (optional partial amount)
